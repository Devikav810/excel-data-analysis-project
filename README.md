# COVID-19 Data Analysis Dashboard Using Excel

## Project Overview

This project presents a COVID-19 data analysis dashboard built using Microsoft Excel. It uses coronavirus summary data to explore reported cases and deaths across countries and summarize key pandemic statistics through data visualization.

The project demonstrates how Excel can transform raw data into a dashboard that supports data exploration and reporting.

## Project Objectives

- Analyze COVID-19 case data across countries.
- Summarize total reported cases and deaths.
- Explore country-level comparisons using summary tables.
- Present key metrics in a visual dashboard.
- Practice data analysis and reporting using Microsoft Excel.

## Tools & Technologies

- **Microsoft Excel**
- Pivot Tables and aggregated summaries
- Data visualization and dashboard design
- Data analysis and reporting

## Dataset

The workbook contains a coronavirus summary dataset with country-level information, including:

- Daily new cases
- Cumulative total cases
- Country-level summary statistics

The workbook includes a dashboard sheet and a data summary sheet.

## Dashboard Features

- **Total Cases:** Displays a summary of reported COVID-19 cases.
- **Total Deaths:** Presents the overall reported death count.
- **Country-Level Analysis:** Summarizes case information by country.
- **Visual Reporting:** Organizes key metrics into a dashboard for easier interpretation.

## Project Workflow

1. Import and review the COVID-19 dataset.
2. Organize and summarize the data.
3. Use Pivot Tables to aggregate country-level statistics.
4. Develop dashboard metrics and visualizations.
5. Present the results in an Excel dashboard.
